四个事件接口都是「查找定位 → 载入（注册进原版事件表）→ 触发」；未读档返回 rejected，找不到只返回 not found，不会报错。
path 可用 <game> 前缀显式声明「游戏内部资源目录」，按真实布局写： <game>/assets/game/events、<game>/assets/map/<map>/scenarios/<剧本>； 不写前缀时按资源内路径（game/events）理解。
全局版会搜索所有候选目录（含当前剧本与插件自己的 resources 子目录）；find 版只搜给定 path 下的 event / MissionsEvent 目录。
